# sillysCipher
This is a program to encrypt and decrypt text according to the rules of my custom cipher

# Installation and running the program
Unfortunately, this app currently must be runned as a program within an IDE (Integrated Development Environment)

- 1: Have Intellij Idea installed on your machine. (On my steam deck I've been using the "Intellij IDEA OSS" package from the Discover store.)
- 2: From within the IDE goto FILE -> NEW -> Project from version control.
- 3: In the menu that have opened up paste this URL "https://github.com/sillythewanderer/sillysCipher.git".
- 4: Then press clone.
- 5: Once the new project opens, then press the green arrow at the top right corner to run the program.
